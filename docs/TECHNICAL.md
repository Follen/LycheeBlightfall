# [荔枝]智能吞病收割提醒

萨莱因邪 DK 的吞病提醒，自动判断单体 / 群怪。设置完整放在暴雪「Esc → 选项 → 插件 → [荔枝]智能吞病收割提醒」中，符合天赋条件时自动注册。

## 安装

把压缩包中的 **LycheeBlightfall** 和 **LycheeBlightfall_Core** 两个文件夹一起解压到正式服 `Interface/AddOns`。首次安装后重启游戏。两个插件都保持启用；核心由入口按需加载。

仅死亡骑士、邪恶专精（252）、萨莱因（英雄天赋树 31），且已选瘟疫降临天赋时启用。其他职业入口直接返回；不符合天赋的 DK 只保留轻量资格检查。已加载过的 Lua 无法卸载，切出天赋会注销核心事件、取消计时器、隐藏提示。

## 使用

- 默认提前 **3 秒**显示 `准备吞病 3.0s`，同时播报「准备吞病」。计时到零显示「准备吞病」。
- 单体和群怪统一显示 `准备吞病 3.0s`，不再显示缠绕或消耗括号的操作提示。内部仍根据成功施法推算脏腑之力和突变续时，不会为了等未出现的括号拖延。
- 文字和语音可分别开关、分别设置提前量（0–10 秒，步进 0.5 秒）。
- 点击「解锁位置」自动关闭设置，拖动提示后点「完成」锁定。可重置位置、调整字号。
- 支持 SharedMedia 音效选择、试听；内置所需库和「温暖少女」默认语音，不需要额外安装依赖。
- 修改设置会清除当前推算，从下一次黑暗突变开始应用。
- 设置底部三个图标分别打开鸣谢、荔枝启动器、荔枝天赋。下载面板提供新手盒子、网易 DD 链接，点击选中后按 Ctrl+C 复制。
- 鸣谢：小当家 Chef（头像由用户提供）。

## 实时推算规则

每次玩家自己的相关技能**施法成功**后更新，倒计时允许后推，以最新建议时机为准，不再锁死。文字一旦出现，本轮保持可见并更新剩余秒数；语音每轮最多一次，续时后不重复喊。

1. 黑暗突变（施法 ID 1233448）成功：建立 15 秒窗口。
2. 窗口内凋零缠绕（47541）、传染（207317）、替换缠绕（1242174）或替换传染（383269）成功：延长 1 秒。按施法 GUID 去重。
3. 自动数可见的、活着、可攻击、已进战的非玩家姓名板。至少 3 个使用群怪分支，否则使用单体分支；没有手动选项。姓名板增减、状态事件及关键推算节点更新数量，不逐帧扫描。
4. 单体：学习 Reaping（377514）且观察到灵魂收割（343294）成功，建立 8 秒收割窗口，按收割结束时间推算。遵循 SimC 单体分支，不再额外取突变和收割的较早结束时间。
5. 群怪：不受收割限制，按突变结束时间推算。如果观察到自己使用乌拉特克贪婪之心（1297761），推算其 20 秒增益，在仍有效的心脏与突变窗口中取较早的结束时间。错过心脏时回到仍有效的突变窗口。不推算其他饰品。
6. 建议出手时间 = 当前限制窗口结束时间 − **2 个 GCD**。优先采用最近观察到的公共 GCD 时长；取不到时按 1.5 秒一个 GCD 预留。
7. 单体没观察到本轮收割时，先按突变窗口给出建议；后续观察到收割会立即重新计算。当前单体收割窗口已过就结束本轮提示，不再改用突变继续催促。
8. 已选脏腑之力天赋（434157）时，监听公开的末日突降括号 SHOW/HIDE 事件（81340）。观察到出现后的一次缠绕/传染成功，推算脏腑之力（434159）持续 5 秒。普通施法不续时，重复 SHOW 不算新触发，不推测剩余层数；括号观察最多保留 10 秒，接近到期不作消耗推断。
9. 已推算的力量能覆盖原建议时间，就按原时间吞病；力量会提前过期，不因此提前吞病。缺少力量也不会后推吞病时间。成功施法后仍实时计算突变续时和本次 GCD。0.3.3 起仅显示准备吞病，不再输出先消耗括号的操作提示；力量覆盖属于内部推断，**不是 SimC APL 的额外硬条件，也未经过 DPS 对比证明提升**。
10. 吞病（实际施法 ID 1271967）成功或窗口结束时清除本轮提示；死亡、脱战、进入世界、开始新钥石或资格/设置改变时同时清空推断历史。不会等技能图标替换或读取秘密光环。

例如：突变预计 20 秒结束、收割 18 秒结束、GCD 1 秒，建议第 16 秒吞病。之后缠绕把突变延长到 21 秒，收割仍在 18 秒结束，建议仍是第 16 秒。没有收割时，同样的续时会把建议时间后推 1 秒。

这是按已发生事件推算的建议，不是完整 SimC DPS 求解器。2 GCD 是借鉴 APL 的出手余量，不是证明所有装备、操作下伤害最高。未来施法、疾病、实际收割命中、换目标、宠物死亡/增益被移除等不可完整推知；疾病由玩家确认。括号事件缺失、秘密值或无法注册时自动退回原吞病逻辑；HIDE 先于成功施法、未观察到的刷新/多层消耗会保守漏算，不把消失当作消耗。未使用技能替换状态。战斗中 `/reload` 会失去本轮施法历史，需下一次突变重新建立窗口。

请开启敌方姓名板。这个计数只覆盖已显示且状态公开的敌人，超出显示范围、姓名板关闭会漏数；进战也不证明该怪正在和你的小队交战。秘密状态不会用于运算，也不会当作已知敌人。源码未标注相关计数接口的秘密返回，但仍未在 M+ / 团队副本战斗实测，详见 `../Analyze/nameplate-aoe-audit.md`。

## 性能与秘密值

没有常驻 OnUpdate、光环扫描或战斗日志解析。符合条件时监听玩家施法及姓名板事件；选中脏腑之力才额外监听两个括号事件。推算窗口内才监听冷却更新，并只查询公共 GCD（61304）。定时唤醒负责文字/语音门槛、准备阶段与过期；只有文字可见时启用 0.1 秒刷新。秘密值先检查再使用，无法安全处理的施法事件会放弃本轮推算；秘密括号事件仅撤销括号推断，不停用基础提醒。
