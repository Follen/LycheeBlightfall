# 收割提醒 1.0.1

按用户最终要求，单体、AOE 采用相同提醒节奏。AOE 吞病仍走原突变/饰品分支。

- 依据本地 SimC 4c7c736 的单体 APL：突变有效且其 CD <38 秒。技能数据基础 CD 45 秒，因此采用成功施法后 7.01 秒作为提示目标。7.01 避免把严格小于比较变成等于；不是未来技能执行时刻保证。
- 缠绕/传染延长宠物突变持续时间，不延长这个 CD 推算目标。
- 需已学 Soul Reaper 和 Reaping；默认收割提醒开关开启。
- 共用提前量（默认 3 秒）、字号和位置；两种音效分别选择。收割每轮语音最多一次，打出收割或吞病、死亡、脱战、重载/资格变化后取消。吞病在显示或播报阶段优先，避免两个指令同时抢同一行。
- 不读取目标血量，不模拟低于 35% 时额外的斩杀收割，也不预测高优先级技能/实际 GCD 占用后的精确执行时刻。
- AOE 延后提示是用户明确选择；SimC AOE 本身不含 CD <38 秒条件。
- 复用现有事件和单个唤醒定时器，没有新增常驻扫描或 OnUpdate。

语音仍使用 MiniMax speech-2.8-hd、Chinese (Mandarin)_Warm_Girl、speed 1.1、vol 1，FFmpeg volume=1.6、libvorbis q5，与吞病一致。随后增加 1.6 dB 匹配现有语音响度：两者 mean_volume 均为 -18.3 dB；新语音 peak -5.4 dB，旧语音 -5.1 dB，无削波。密钥仅通过隐藏终端输入，不持久化。输出 prepare-reaper.ogg，合成接口报告 972 ms，OGG 解码约 0.94 秒。

366 个断言通过。验证包含双提醒计时、单体/AOE、成功收割取消、未收割时吞病接管、早收割、缺少天赋、重复事件、续时不移动提醒及共享显示行切换。游戏内新增功能尚待实测。
