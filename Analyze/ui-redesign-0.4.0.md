# 0.4.0 设置页交付检查

## 改动

沿用 Lychee Talent 的配色、圆角和控件风格，减少说明文字。设置仍在暴雪统一插件选项内。解锁先调用 SettingsPanel:Close(true)，关闭成功后进入拖动，点击「完成」锁定；原生设置待确认时不进入拖动。

底部固定鸣谢、荔枝启动器、荔枝天赋三个图标。鸣谢使用用户头像及「小当家 Chef」。两个下载面板分别展示用户提供的新手盒子、网易 DD 链接，点击全选、Ctrl+C 复制，不声称自动打开浏览器或自动复制。弹窗可点外侧、关闭按钮或 Esc 关闭，离开设置自动收起，按需创建并复用。
