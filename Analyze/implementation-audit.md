# 实现审计 · 2026-09-28

以下是 0.1.0 的历史审计；0.2.0 新增的自动群怪分支、姓名板及心脏推算见 `nameplate-aoe-audit.md`。

版本 0.1.0。用户最后要求「同步后推时间实时计算，不必把窗口写死」，已替换先前的首次提示锁定方案。

## 已处理

- 实时重算 DT / SR 窗口与建议时刻。已观察到 SR 时同时受两者限制，延长 DT 不会越过 SR；SR 过期停止本轮，不回退到仍存续的 DT。
- 文本提示出现后不因续时而闪隐；目标时刻实时更新。语音每轮最多一次，默认文字/语音分别提前 3 秒。
- 去重覆盖普通和替换缠绕；仅观察施法成功，无伤害事件重复延长。
- 非 DK 不创建入口事件框架；不符合萨莱因邪 DK + 吞病天赋的条件不加载核心。核心按需加载且依赖入口。已加载后切天赋会停用事件/计时器。
- 专精接口采用当前源码的 C_SpecializationInfo 命名空间。IsSpellKnown 的 spellBank 参数使用文档明确的 Player 默认值。
- 公共 GCD 61304：先检查返回对象与字段是否秘密值，再计算 duration/modRate。零时长忽略；缺少新鲜观测按 1.5 秒回退。绝不查询 UnitSpellHaste 推导秘密急速。
- 对成功事件 unit/spellID/GUID 先检查秘密值，无法安全处理即清除不可靠的本轮。清理取消定时器，并用 generation 阻止过期回调恢复提示。
- 暴雪原生设置画布；直接包含控件。位置解锁使用 HideUIPanel(SettingsPanel)，避免不存在的 Settings.CloseSettingsPanel 调用。
- 没有常驻 OnUpdate；数字 ticker 只在可见时运行。媒体库原样内嵌、许可证一并保留。
- MiniMax 默认语音生成成功，OGG Vorbis / 单声道 / 32000 Hz，约 1.08 秒。生成工具通过隐藏输入或环境变量读取凭据；插件不含在线请求或密钥。

## 尚未证明

离线测试只验证状态机及事件处理，不等于游戏 API 的实际秘密策略。lycheedev 静态检查仍报告 complete=false、interfaceStatus=unresolved，动态绑定、参数类型、战斗、taint 和运行表现不在覆盖内。

未在游戏内安装或接管他人占用的客户端。原生设置布局、音频实际播放、M+ / 团本战斗中的事件可见性及推算误差仍需实测。

仅凭施法无法观测目标疾病完整状态、实际命中、增益被驱散/移除、宠物状态和未来操作。当前结果是可实现的事件推算提示，不声称所有场景的数学最优或完整 SimC APL。特别是未打收割时可以先进入 DT 保底提示；后来才打收割会更新倒计时，已有语音不会重播。
