# 荔枝邪DK吞病

[English](README.en.md) · [更新日志](Changelog.md)

![Cover](docs/media/release-cover.png)

专为正式服萨莱因邪 DK 准备的吞病提醒。接近建议时机时，屏幕显示「准备吞病 3.0s」，同时播放语音，让你少盯一个计时，多看一眼战场。

## 跟着这一轮爆发走

根据你的成功施法推算黑暗突变、灵魂收割等窗口，给出吞病倒计时。缠绕、传染续长突变后，建议时间也会更新；已经出现的文字会继续显示，语音每轮最多提醒一次。

根据可见且已进战的敌方姓名板自动区分单体和群怪，不需要手动切换。请开启敌方姓名板，方便判断。

## 提醒，按自己的习惯来

- 默认提前 3 秒显示文字并播放「准备吞病」。文字与语音可以分别关闭、分别调整提前量。
- 拖动调整位置，自由设置字号；提示背景透明。
- 内置默认语音，支持 SharedMedia 音效选择和试听。
- 设置直接放在「Esc → 选项 → 插件 → 荔枝邪DK吞病」。点击「解锁位置」会关闭设置，拖好后点「完成」。

## 装好就能用

适用于正式服 12.1、邪恶专精、萨莱因英雄天赋，并且已选择瘟疫降临。符合条件后自动启用；无需 WeakAuras 或荔枝启动器。

使用平台客户端安装即可。手动安装时，把压缩包里的 LycheeBlightfall 和 LycheeBlightfall_Core 两个文件夹一起放进正式服 Interface/AddOns，两个都保持启用。首次安装后重启游戏。

## 使用时记住这一点

倒计时是按已发生的施法推算的建议，不会替你施法，也不保证每种装备和战斗场景都达到最高伤害。换目标、宠物状态变化、敌人超出姓名板范围等情况可能影响判断，请结合战况决定。战斗中重载界面后，需要下一次黑暗突变重新开始推算。
